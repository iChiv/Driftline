## 可以使用的入口

- Unity：打开 `Assets/Scenes/SampleScene.unity`，Play 后选择本地游戏或局域网。本地自由配置人类/电脑，不再分单人和同机两个入口。
- Windows：`Builds/Driftline-Dev.exe`；复制到另一台电脑推荐使用 `Builds/Driftline-Windows-LAN.zip`，解压后运行同名 exe。
- UI：`Assets/UI/Prefabs/UIRoot.prefab`，或场景 UIRoot 实例。选中 DraftlineCanvasUI 组件可以在 Inspector 预览六个页面；所有正式控件已保存，运行时绑定状态和事件。
- 动态文案：`Assets/UI/Config/MatchTextContent.asset`；棋盘提示：BoardInteractionStyle 与 BoardInteraction Prefab；特效：`Assets/Themes/Driftline/MatchFeedback.asset`；音乐：Draftline Game/Background Music。
