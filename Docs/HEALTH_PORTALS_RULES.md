# 生命、棋子与传送门修订

2026-10-15 用户确认的新规则，覆盖旧 V0.3 文档中对应条款。其他回合、道具、五连与墙切换顺序沿用原实现。

## 传送门

- 配对出口的落点固定为门朝棋盘中央的相邻格，不受进入方向影响。
- 出口门格或落点被棋子占据，或落点不可进入时，整个传送不发生，停在入口前；撞吃不绕过这个检查。
- 一次传送包含入口、配对门、中央侧落点三个演出步骤；急停不能停在两个门格中间，只能选择真正的可停留格。
- 两端朝中央的门口在两个门格未被占用时连通。远端门口为空地，提供一口气；远端为同色棋，两边组成同一棋块，共享外部气；敌棋堵住门口则不提供气。
- 两端同色棋块的外部气全部被封住，也会进入新增无气的围杀结算。禁止自吃、既有无气不追溯、墙切换独立结算保持。
- 穿墙效果仍绕过传送，不触发跳跃。

## 生命与棋子

- 每方初始生命 5，开局 1 子，另有 7 个备用位置；场上最多 8 子。
- 每被吃 1 子扣 1 生命，被吃棋子回备用池，可按原规则重新部署；重新部署不恢复生命。
- 生命为 0 时立即出局，清除该方其余棋子并跳过其后续回合。撞吃可以在滑行次数尚未用完时直接淘汰对方。
- 五连仍在原有回合结算时机获胜；最后存活的一方也获胜。
- 如果同一次机关墙结算让所有剩余方同时失去最后生命，结束为平局，避免寻找下一玩家时无限循环。
- `Consumed` 仅保留为历史被吃次数统计，不参与死亡判定。

## 呈现与联机

- HUD 显示生命 x/5 与场上 x/8，行动说明与日志显示扣血结果。
- 玩家可选主题仅前线要塞、符文地城、星舰机库、暮林祭坛、潮汐港口；旧桌面资源保留为内部历史资源。
- 环境自动随机；玩家菜单不再提供状态选项。房主发送实际环境与种子，客户端和重连跟随。
- 菜单保留场景全景，对局默认镜头距离 26；滚轮可在 20–36 间缩放，指针位于 UI、设置或规则引导时不缩放棋盘。
- 镜头参数保存于场景 `Draftline Game / DraftlineCameraDirector`，菜单位置和状态控件显隐保存在 `Assets/UI/Prefabs/UIRoot.prefab`。
- 生命进入深复制、网络快照和电脑评估；新契约 `board19-health5-pieces8-portals-5` 拒绝旧规则客户端。

验证与新试玩包记录位于 `Docs/Validation/HealthPortals`。
