# 两台 Windows 电脑局域网试玩

推荐将 `Builds/Driftline-Windows-LAN.zip` 复制到第二台电脑并完整解压，两台运行其中的 `Driftline-Dev.exe`。项目内入口为 `Builds/Driftline-Dev.exe`；若手工复制，保留 Driftline-Dev_Data、UnityPlayer.dll、MonoBleedingEdge 和字体授权等依赖。不要使用历史 `DraftlineDemo.exe`。两台使用同一份构建，连接同一局域网。

1. 房主打开游戏 → 局域网，选 2/3/4 方。先用 2 方测试人类对局；再用 4 方并启用“空位由电脑补齐”。默认端口 `7777`。
2. 点击创建房间，将房间页显示的实际 IPv4 和端口告诉另一位玩家。可能显示多个网卡地址，应使用两台共同连接的 Wi-Fi/以太网地址。
3. 第二台打开局域网页，输入房主 IPv4 和同一端口，点击加入。**127.0.0.1 只用于同一台电脑。**若 Windows 提示网络访问，允许此程序访问当前私人网络。
4. 加入者选择空闲颜色并准备；房主已默认准备，所有人就绪后由房主开始。开启电脑补位时未占用的有效席位由电脑操作。
5. 轮到自己时点击桌面骰子或投掷按钮；点击己方棋子 → 查看路径 → 点击终点。道具可从棋子旁按钮选择；急停直接点击金色路径停点。多条路径共用终点时先点击棋子旁的方向箭头。

## 必须确认的体验

- 两端人数、颜色、骰子、剩余滑行、库存和棋子位置一致；本方可以点按，对方回合无法提交。
- 出子不消耗滑行；取消预览不消耗道具。实际动作提交后，远端播放移动/传送及完整事件，随后状态一致。
- 覆盖穿墙、急停、撞吃、破墙、传送、墙切换、围杀、出局和两种胜利。先验证 2 方，再验证人类+电脑的 3/4 方。
- 非房主临时断网后，房主保留席位，轮到掉线者时等待。**同一程序实例在 60 秒内**点“重新连接”可恢复原席位与快照；身份只保存在当前进程，关闭程序再开不能恢复原身份。
- 房主可选择“电脑接管掉线玩家”，之后该席位不再为原连接保留。房主退出后客户端显示断开提示，可在设置中返回菜单；本版没有房主迁移。
- 胜利后由房主再开局，双方返回房间并重新准备；客户端不会转成单机棋局。
- 局域网设置页只停止本机输入，电脑和其他玩家仍可推进；本地/单人设置页会暂停电脑决策和本机输入。

真实两台设备的网络、防火墙与人工完整对局尚待试玩验收。同机双进程已经用于权威状态摘要和重连验证，不能代替这一项。

行动原因版本的契约为 `board19-v03-reasons-2`，事件新增吃子原因字段。两台均使用更新后的试玩包；旧包与新包会按版本不一致拒绝连接。

## 开发验证入口

Development Build 支持可选参数 `--driftline-lan-smoke --role host|client --port 7788 --report <absolute-jsonl-path>`，配合 `-batchmode -nographics -logFile <absolute-log-path>` 用于同机独立进程验证。探针在没有此参数时不启动，Release Build 不包含它。

探针等待两名人类席位，补两名电脑；两端通过正式命令接口行动，客户端在 revision 6 后断线并重连，记录至少到 revision 24。比较相同 revision 的完整快照 SHA256。它只检查同步和生命周期，不评价操作直观程度或美术，也不代替物理鼠标和真实 LAN 试玩。
