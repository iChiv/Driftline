# 界钥棋庭

古老遗迹中的界钥重新苏醒。四支探索队通过各自的符文印记投射傀儡，在周期升降的机关墙之间争夺通路。五枚棋子形成共鸣线即可唤醒界钥；成为最后存活的一方也能取得它。

| 阵营 | 动机 | 标记 |
| --- | --- | --- |
| 赤炉 / 红 | 寻找界钥，重启地下炉城 | 炉 |
| 苍印 / 蓝 | 封存遗迹知识，阻止机关失控 | 印 |
| 苔庭 / 绿 | 守望苔庭，阻止遗迹侵蚀地表 | 庭 |
| 金环 / 黄 | 沿金环指引，寻找失落城邦 | 环 |

阵营身份仅用于文案和视觉，各方规则与能力相同。按最新确认规则，每方 5 点生命、场上最多 8 子，被吃扣 1 点生命且棋子回备用池；生命归零出局。围杀表现为投射解除，不引入职业或装备系统。详见 [当前规则修订](HEALTH_PORTALS_RULES.md)。

保留桌面微缩棋庭：暖木桌、浅色格子、深灰固定低墙、黄铜机关墙、四色阵营印记。传送门以成对的形状标记辅助原有颜色。外围旗帜和少量探索物件提供故事线索，棋盘内保持规则轮廓与点按空间。

开局短文保存于 UIRoot 的 MainMenuPanel/MenuCard/Story，可直接编辑；阵营背景和结局保存于 MatchTextContent。单人、同机与 LAN 共用这些内容。当前没有独立剧情关卡、过场或影响平衡的阵营技能。

视觉验收重点：默认/俯视能读清四角；正常终点、急停停点、机关墙与阵营门可分辨；传送路径分段；围杀/胜利演出不遮挡下一次操作。当前版本是可继续手工打磨的统一主题场景，最终美术与音频观感以试玩审阅为准。
