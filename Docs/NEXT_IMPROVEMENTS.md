# 试玩后的下一轮建议

按用户要求，行动原因与规则引导已实施，电脑演出加速与存档不做。现有规则和普通 AI 保持。接下来的美术部分仅梳理 [多主题棋盘计划](Art/THEME_BOARD_PLAN.md)，未制作主题。

| 顺序 | 改进 | 可检查的结果 |
| --- | --- | --- |
| 1 | 行动原因，已实现 | 独立预览完整动作和即时结算，预测吃子红圈；不消耗实时 RNG，也不公开未来道具；实际事件区分接触/围杀/墙变化 |
| 2 | 规则引导，已实现 | 主菜单、配置、HUD、设置可打开七段引导，包含文字与符号示例，可随时关闭；文案和 UI 可编辑 |
| 3 | 多主题美术，只规划 | 五个完整场所、模型用法、外围构成、材质/尺度适配、未来主题契约和制作顺序 |

另需使用第二台 Windows 完成真实 LAN 试玩，重点记录不同设备的点击、掉线/接管/重开局和完整胜利。用户的一局体验反馈不能代替多人和网络各流程验收。

本轮不加入演出加速、存档、悔棋、阵营能力或新棋盘规则。
