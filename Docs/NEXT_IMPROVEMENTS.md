# 试玩后的下一轮建议

按用户要求，行动原因与规则引导已实施，电脑演出加速与存档不做。2026-10-15 进一步授权制作后，五个场所主题首版与主菜单切换已完成，见 [制作结果与编辑入口](Art/THEME_IMPLEMENTATION.md)。现有规则和普通 AI 保持。

| 顺序 | 改进 | 可检查的结果 |
| --- | --- | --- |
| 1 | 行动原因，已实现 | 独立预览完整动作和即时结算，预测吃子红圈；不消耗实时 RNG，也不公开未来道具；实际事件区分接触/围杀/墙变化 |
| 2 | 规则引导，已实现 | 主菜单、配置、HUD、设置可打开七段引导，包含文字与符号示例，可随时关闭；文案和 UI 可编辑 |
| 3 | 多主题美术，首版已实现 | 五个模型场所、外围构成、兵棋、材质适配与合批；主菜单六选一预览，LAN 统一房主主题 |

本轮不加入演出加速、存档、悔棋、阵营能力或新棋盘规则。
