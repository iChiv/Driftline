# HUD 与棋盘提示整理

本轮只改善 Unity 呈现，保持已确定的棋盘、规则、电脑策略与网络协议。

- 左侧整块底板改成回合、道具、席位状态三组卡片。空道具卡、空行动说明、空事件记录隐藏，空白处可继续点击场景。
- 席位卡自动排列，关闭席位不占空间。回合色条与阵营卡保持一致。
- 普通终点是圆形箭头，急停停点是切角方形与方块符号；加入深色描边和悬停提亮／放大反馈。
- 行动说明根据内容收缩；超过最大高度时可滚动，切换说明返回顶部。
- 选中棋子后的道具提示和掷骰按钮文案随当前阶段更新。
